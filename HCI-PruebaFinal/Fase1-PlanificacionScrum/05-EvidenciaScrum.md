## Ceremonias Scrum

### Sprint Planning
- [x] Revisar backlog con equipo
- [x] Definir objetivos del sprint
- [x] Asignar historias y estimaciones
- [x] Identificar dependencias y riesgos

### Daily Standup
- Frecuencia: diaria
- Formato: 3 preguntas
  - ¿Qué hice ayer?
  - ¿Qué haré hoy?
  - ¿Qué impedimentos tengo?

### Sprint Review
- Revisar entregables con stakeholders
- Demostrar funcionalidades completadas
- Recoger feedback para el siguiente sprint

### Sprint Retrospective
- Analizar qué salió bien
- Identificar mejoras del proceso
- Definir acciones para el siguiente sprint

## Roles Scrum

### Product Owner
- Priorizar backlog
- Aceptar entregables
- Validar criterios de aceptación

### Scrum Master
- Facilitar ceremonias
- Remover impedimentos
- Asegurar que el equipo sigue Scrum

### Development Team
- Implementar las historias
- Escribir pruebas
- Realizar code review
