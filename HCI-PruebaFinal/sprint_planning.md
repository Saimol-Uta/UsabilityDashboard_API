## 1. Objetivo del Sprint (Sprint Goal)
**Entregar un Dashboard optimizado** (resolviendo problemas de desorientación espacial) integrando **Navegación Contextual (Breadcrumbs)** reales en el código base, respaldado por una auditoría heurística en Fase 1, diseños en Figma (Fase 2) y trazabilidad completa vía GitHub (Fase 3).

---

## 2. Parámetros del Ciclo
- **Duración:** 1 Mini-Sprint Intensivo (Simulado como 1 semana).
- **Capacidad:** 2 Horas directas de enfoque técnico continuo.
- **Herramientas:** React/Vite, TailwindCSS, Markdown, Python (Wireframes generados dinámicamente) y Git CLI.

## 4. Definition of Done (DoD)
Para que cualquier tarea sea considerada finalizada, debe cumplir:
1. Resuelve directamente un problema de Usabilidad detectado en las Heurísticas.
2. Contiene **Evidencia tangible** (Código o Artefacto Visual).
3. Documentación Markdown generada con estilo, orden y clara nomenclatura.
4. Ha sido incluida en un Commit dentro del repositorio central (GitHub).
